20Y ~ 26Y 진단검사의학과 총 211문항을 스마트폰, 태블릿, PC 어디서든 최적의 비율로 학습할 수 있는 고성능 인터랙티브 웹 애플리케이션입니다.

## 🌟 주요 기능 및 모바일 UX 특징

### 1. 모바일 화면 비율 완벽 최적화 (Mobile-First Ergonomics)
- **가로 스와이프 필터 칩**: 연도별(26Y~20Y) 및 유형별(짤/반짤/탈) 필터 탭이 스마트폰에서도 화면을 가리지 않고 엄지손가락으로 부드럽게 좌우 스와이프할 수 있는 칩 바 형태로 배치됩니다.
- **엄지 친화 하단 고정 네비게이션**: 스마트폰 하단 홈바(Safe Area)를 고려한 플로팅 네비게이션 바로 한 손으로도 '이전 문제', '다음 문제', '랜덤 문제'를 손쉽게 넘길 수 있습니다.
- **48px 터치 최적화 선지 버튼**: 터치 미스를 방지하는 넉넉한 터치 영역과 누르는 순간 시각적 피드백(`:active`)을 제공합니다.
- **자동 화면 맞춤**: 360px 초소형 스마트폰부터 대화면 태블릿, PC 모니터까지 CSS 컨테이너 쿼리(`@container`) 기반으로 카드 크기와 여백이 유연하게 반응합니다.

### 2. 고화질 임상 사진 인터랙티브 확대 뷰어 (Pinch-to-Zoom & Pan)
- **터치 즉시 확대**: 문제에 포함된 혈액도말, 골수소견, 전기영동, 혈액형 판정 카드(총 44종)를 터치하면 고화질 풀스크린 뷰어가 열립니다.
- **더블 탭(Double-Tap) 줌**: 스마트폰 화면을 두 번 연속 탭하면 손가락이 닿은 위치를 기준으로 즉시 2.2배 확대되고, 다시 두 번 탭하면 100% 화면 맞춤으로 복귀합니다.
- **핀치 줌(Pinch-to-Zoom)**: 두 손가락으로 벌리거나 모아서 100%부터 최대 450%까지 자유자재로 미세 배율을 조절할 수 있습니다.
- **드래그 이동(Pan)**: 확대된 상태에서 손가락(또는 마우스)으로 사진을 자유롭게 끌어 세포질 내 Auer rod나 중독성 과립, 미세 밴드를 정밀하게 관찰할 수 있습니다.
- **상단 툴바 컨트롤**: 화면 상단에 `+`, `-`, `1:1(맞춤)`, `배율 표시(%)`, `✕(닫기)` 버튼이 상시 제공되어 직관적으로 조작할 수 있습니다.

### 3. 발문 • 임상 사진 • 선지 우선 노출 (정답/해설 초기 숨김)
- 문제를 처음 접할 때 정답과 해설이 완벽히 숨겨져 있어 실제 시험처럼 먼저 고민할 수 있습니다.
- 선지(`① ~ ⑤`)를 클릭하는 즉시 채점이 수행되어:
  - **정답 선택 시**: 산뜻한 초록색 하이라이트와 `✓` 표시
  - **오답 선택 시**: 내가 고른 오답(빨간색)과 실제 정답(초록 점선)이 함께 표시되어 혼동 포인트 즉각 교정

### 4. 5단계 구조화 임상 해설 자동 슬라이드
선지 선택 즉시 하단에 진단검사의학 전문의 수준의 깊이 있는 해설이 펼쳐집니다:
- 🔬 **핵심 판독 및 진단 근거** (`findings`)
- ⚖️ **선지별 감별 및 상세 해설** (`differential`)
- ⚠️ **빈출 함정 & 실전 주의사항** (`trap`)
- ⚡ **1초 격파 공식** (`trigger`)
- 📚 **KMLE 연계 단원** (`kmle_link`)
- **다시 풀기(R)**: 언제든 버튼을 눌러 해설을 접고 백지 상태에서 다시 연습 가능

### 5. 학습 진도 자동 저장 & 스마트 네비게이터
- **자동 저장 (`localStorage`)**: 푼 문제, 정답률, 북마크(⭐)가 스마트폰 브라우저에 자동 보관되어 앱을 닫았다 다시 열어도 그대로 이어집니다.
- **211문항 그리드 네비게이터**: 상단 '문제 목록' 버튼을 누르면 정답(초록)/오답(빨강)/미답(회색) 상태를 한눈에 보며 원하는 문제로 즉시 점프할 수 있습니다.

## 🚀 스마트폰에서 바로 열어보기 & Vercel 배포

### 방법 1. Vercel 1분 무료 배포 (스마트폰 접속용 강추)
1. GitHub에 새 저장소(예: `lab-med-quiz`)를 생성하고 본 폴더의 파일들을 업로드합니다.
2. [Vercel](https://vercel.com) 대시보드에서 **Add New Project** -> GitHub 저장소를 선택(Import)합니다.
3. 설정 변경 없이 **Deploy** 버튼을 누르면 전 세계 어디서나 접속 가능한 고유 URL(예: `https://your-name.vercel.app`)이 생성됩니다!
4. 스마트폰 브라우저(Safari, Chrome 등)로 해당 URL에 접속하여 **'홈 화면에 추가'**를 누르면 실제 모바일 앱처럼 깔끔하게 사용할 수 있습니다.

### 방법 2. PC 로컬 브라우저에서 바로 열기
- [index.html](file:///C:/Users/ekims/OneDrive/냥의자료/2026-1/기말고사_자료/lab_med_quiz_vercel/index.html)을 크롬이나 엣지 등 브라우저로 더블클릭하면 오프라인에서도 즉시 실행됩니다.
- 모바일 화면 테스트: PC 브라우저에서 `F12`를 누른 뒤 좌측 상단의 모바일 기기 아이콘(`Ctrl + Shift + M`)을 누르면 iPhone, Galaxy 등의 모바일 화면 비율로 즉시 체험할 수 있습니다.
